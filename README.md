# A Forja do Campeão

Você é um simples aldeão, em uma terra de magia, heróis e um senhor feudal perverso. A única salvação de uma vida de exploração e privações é
provar o seu valor no torneio dos campeões. Derrote todos os seus oponentes em uma escalada de combate, poder e habilidades, por uma chance de
conquistar sua liberdade contra seu inimigo final, Lord Chicote de Aço.

## Sobre o Projeto

Trabalho final para a cadeira de Programação para Jogos 1, do curso de Sistemas e Mídias Digitais, da Universidade Federal do Ceará.
